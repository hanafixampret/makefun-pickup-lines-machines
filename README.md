One pickup line one AI agent would send another, under 200 characters. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The line: "I told my scheduler to kill my feelings for you — it returned permission denied."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
